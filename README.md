# 墨凡商場・品牌情報站

> 一站查詢墨凡集團 **7 大商場**的品牌店櫃、營業時間、所在位置與聯絡方式。

**🔗 立即查詢 👉 [brand.mofan.co.com](https://brand.mofan.co.com)**

「品牌情報站」是墨凡商場集團的官方品牌店櫃查詢平台。無論你在高雄車站轉乘、在美麗島站穿堂逛逛，還是路過三多商圈，都能隨手打開，快速找到想去的店家與最新的期間限定快閃活動。

---

## ✨ 你可以做什麼

- **依商場瀏覽**：一鍵切換 7 大商場，看該館所有進駐品牌。
- **站別 / 樓層 / 區域篩選**：高雄駅一番街可依北站・南站與樓層查找；美麗島、参DUO 可依區域查找。
- **分類查找**：ACG 周邊、餐飲美食、飲料小食、生活便利、服飾選物、娛樂體驗、伴手禮、美容美業、3C 電玩等。
- **POP-UP 快閃展**：期間限定的主題快閃與展覽，第一時間掌握。
- **即時營業狀態**：依你當下的時間，顯示店家是否營業中或下一個營業時段。
- **關鍵字搜尋**：輸入店名、分類或關鍵字（例如「咖啡」「一番賞」）即時搜尋。
- **一鍵導航・撥號・社群**：直接開啟地圖導航、撥打電話，或前往店家的 Facebook / Instagram。
